# DentAssist Pro — نسخة الويب (هاتف / تابلت / حاسوب)

نسخة الويب **منفصلة** عن مثبّت Windows (`.exe`). بناء سطح المكتب لا يتأثر:

| الأمر | الغرض |
|--------|--------|
| `npm run dist` | تطبيق Electron كما كان |
| `npm run build:web` | موقع ثابت في مجلد `dist-web` |
| `npm run dev:web` | معاينة محلية على الشبكة (للهاتف) |
| `npm run serve:web` | بناء + خادم معاينة |

## التجربة على الهاتف أثناء التطوير

1. على الحاسوب: `npm run dev:web`
2. اعرف IP الشبكة (مثلاً `192.168.1.10`)
3. على الهاتف (نفس Wi‑Fi): افتح `http://192.168.1.10:5173`
4. أندرويد: من القائمة → «إضافة إلى الشاشة الرئيسية» (PWA)
5. iOS: Safari → مشاركة → «إضافة إلى الشاشة الرئيسية»

## النشر للإنتاج

1. `npm run build:web`
2. ارفع **كل** محتويات `dist-web` إلى الاستضافة (Netlify، Vercel، nginx، IIS…)
3. يجب تقديم الملفات عبر **HTTPS** حتى يعمل التخزين المحلي و Service Worker
4. التوجيه يستخدم `HashRouter` (`#/patients`) — لا حاجة لإعادة كتابة مسارات على الخادم

## ملاحظات مهمة

- البيانات على الويب تُخزَّن في **IndexedDB** على جهاز المستخدم (ليس على خادمك ما لم تضيف مزامنة سحابية لاحقاً).
- نسخة `.exe` تستخدم SQLite على القرص؛ الوظائف السريرية متطابقة عبر جسر `webBridge`.
- ضع `build/icon.png` قبل البناء لنسخ شعار PNG تلقائياً إلى `public/logo.png` (اختياري).

## النسخ الاحتياطي والاستعادة (حاسوب ↔ هاتف)

1. **على الحاسوب** (exe أو موقع): الإعدادات → نسخ احتياطي → كلمة مرور (8+ أحرف) → **تنزيل/تصدير** ملف `dentassist-backup-YYYY-MM-DD.dentassist`.
2. **انقل الملف** إلى الهاتف (واتساب، Google Drive، USB، بريد…).
3. **على الهاتف** (الموقع أو PWA): الإعدادات (حساب **طبيب**) → اختر الملف → نفس كلمة المرور → **استيراد واستعادة**.
4. تُستبدل بيانات الهاتف بالكامل بنسخة الحاسوب؛ تُعاد تحميل الصفحة تلقائياً.

نفس الملف المشفّر يعمل في الاتجاهين (هاتف → حاسوب عبر استيراد في exe).
